# Vídeos do Gestor Easy, organizados por tema

Acervo de todos os vídeos já produzidos do Gestor Easy, para reaproveitar em postagens futuras e em treinamentos. Todos foram gravados com **dados fictícios** (lojas, clientes, fornecedores e notas de demonstração).

> Este repositório é **público** e o Metricool usa os links dele nas postagens agendadas. Os arquivos que já existiam em `instagram/` e nas branches de cada campanha **não foram movidos**; esta pasta é uma cópia organizada. A trilha de treinamento para clientes fica no repositório privado `gestor-easy-treinamentos`.

## Como cada tema está organizado

| Arquivo | O que é |
|---|---|
| `pc.mp4` | Versão para assistir no computador (horizontal 1920x1080 ou quadrada 1080x1080, conforme o vídeo) |
| `celular.mp4` | Versão gravada com a tela do celular (quadrada 1080x1080) |
| `vertical.mp4` | Versão 1080x1920 para Reels, Shorts e TikTok |
| `roteiro.md` | Texto da narração (ou roteiro das cenas, nos vídeos só legendados) |
| `legenda.md` | Legendas usadas nas redes e agenda da postagem |

## Regras para novos vídeos

1. Criar a pasta do tema com o próximo número (`14-...`) e os arquivos `pc.mp4`, `celular.mp4`, `vertical.mp4` que existirem, mais `roteiro.md` e `legenda.md`.
2. Só dados fictícios na tela.
3. O GitHub recusa arquivos acima de 100 MB.
4. Atualizar esta tabela com data, duração, formatos e onde foi postado.
